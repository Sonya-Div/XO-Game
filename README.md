## 🇺🇸 English Description

An interactive, responsive, and cinematic **Tic-Tac-Toe (XO)** web game built from scratch using clean vanilla web technologies. The project features elegant visual styles, responsive layouts for all devices, and interactive custom logic.

### ✨ Features
* **Cinematic Win Line:** A dynamic red line animates across the winning combination (horizontal, vertical, or diagonal) before revealing the winner.
* **Smart Delay System:** Smooth transitions that wait for the animation to finish before showing the results screen.
* **Fully Responsive:** Beautifully optimized for mobile phones, tablets, and desktop screens.
* **Clean Code Architecture:** Utilizes modular JavaScript array logic and CSS positioning grid layouts.

### 🛠️ Technologies Used
* **HTML5:** Semantic structure and interactive click bindings.
* **CSS3:** Grid Layout, Flexbox, custom absolute positioning, transitions, and Media Queries for responsiveness.
* **JavaScript (ES6):** Array tracking logic, destructuring, turn-switching states, and asynchronous scheduling (`setTimeout`).

## 🇵🇸 الوصف باللغة العربية

لعبة **إكس-أو (Tic-Tac-Toe)** تفاعلية، مرنة، ومصممة بأسلوب سينمائي جذاب للويب من الصفر. يركز المشروع على تقديم تجربة مستخدم سلسة وتصميم متجاوب مع كافة الشاشات باستخدام تقنيات الويب الأساسية الصافية.

### ✨ المميزات
* **خط الفوز السينمائي:** يرتسم خط أحمر تفاعلي ومتحرك فوق المربعات الثلاثة الفائزة (أفقياً، عمودياً، أو قطرياً) بشكل دقيق.
* **نظام التوقيت الذكي:** انتظار مبرمج لثانيو ونصف لكي يرى اللاعب حركة الخط بنعومة قبل نزول ستارة النتيجة البيضاء.
* **مرونة كاملة (Responsive):** متوافقة تماماً وتتجاوب تلقائياً مع شاشات الهواتف الذكية، الأجهزة اللوحية، والشاشات المكتبية.
* **كود نظيف ومنظم:** تعتمد الجافاسكريبت على مصفوفات تتبع مرنة وتفكيك ذكي لعناصر الفوز (Destructuring).

### 🛠️ التقنيات المستخدمة
* **HTML5:** لبناء الهيكل البرمجي الموزون وعناصر اللعبة.
* **CSS3:** لتصميم الشبكة (Grid)، التوسيط (Flexbox)، التموضع المطلق، الحركات الناعمة، و (Media Queries) للموبايل.
* **JavaScript (ES6):** لإدارة منطق اللعبة، تبديل الأدوار، فحص مصفوفة الفوز، والتوقيت الزمني (`setTimeout`).
